# Profit Function

Profit is calculated as (price - cost per unit) multiplied by the quantity sold. Strategies aim to raise profit by changing price, cost, or quantity.

## Key Points
- Profit = (price - cost per unit) x quantity. ([[Class 2 - Value Creation and Capture#The profit function|Class 2 › The profit function]])
- Strategies raise profit by raising price, lowering unit cost, or raising quantity. ([[Class 2 - Value Creation and Capture#The profit function|Class 2 › The profit function]])
- H&H Bail Bonds tried to raise quantity by loosening standards, but this also raised costs. ([[Class 2 - Value Creation and Capture#The profit function|Class 2 › The profit function]])
