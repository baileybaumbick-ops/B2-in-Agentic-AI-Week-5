# Pricing Game

Algorithmic pricing can be used to sustain high prices without explicit agreement, complicating antitrust enforcement.

## Key Points
- Pricing algorithms can learn to sustain high prices without explicit agreement. ([[Class 8 - Strategic and Repeated Interactions#Pricing game and algorithmic collusion|Class 8 › Pricing game and algorithmic collusion]])
- Q-learning agents experiment with prices and learn from profits. ([[Class 8 - Strategic and Repeated Interactions#Pricing game and algorithmic collusion|Class 8 › Pricing game and algorithmic collusion]])
- This makes antitrust enforcement harder. ([[Class 8 - Strategic and Repeated Interactions#Pricing game and algorithmic collusion|Class 8 › Pricing game and algorithmic collusion]])
