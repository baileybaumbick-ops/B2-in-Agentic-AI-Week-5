# Value Creation

Value created is the gap between a customer's benefit and the cost. Firms must create this value before they can capture it.

## Key Points
- Value created is the gap between the customer's benefit (willingness to pay, B) and the cost (C). ([[Class 2 - Value Creation and Capture#Value created and value captured|Class 2 › Value created and value captured]])
- Firms can increase value by increasing benefits, decreasing costs, or increasing quantity. ([[Class 2 - Value Creation and Capture#Value created and value captured|Class 2 › Value created and value captured]])
- A smaller slice of a bigger pie can be more valuable. ([[Class 2 - Value Creation and Capture#Value created and value captured|Class 2 › Value created and value captured]])
- Allbirds raised willingness to pay only for sustainability-minded buyers while raising cost for all. ([[Class 2 - Value Creation and Capture#Value created and value captured|Class 2 › Value created and value captured]])
