# Value Proposition

The value proposition is a statement detailing how a firm intends to create value and bridge the gap between customer benefits and costs.

## Key Points
- Firms create value in different ways, such as Toyota focusing on volume and reliability versus Porsche focusing on performance. ([[Class 5 - Competitive Advantage#Value proposition|Class 5 › Value proposition]])
- The value proposition outlines the plan for opening the gap between benefit B and cost C. ([[Class 5 - Competitive Advantage#Value proposition|Class 5 › Value proposition]])
