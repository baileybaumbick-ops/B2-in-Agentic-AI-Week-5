# Added Value

Added value is the total value created by a firm minus the value created without it, representing what others would pay to keep the firm.

## Key Points

### From Class 3 - Added Value and Irreplaceability
- Added value equals total value created with you in the market minus total value created without you. ([[Class 3 - Added Value and Irreplaceability#Defining added value|Class 3 › Defining added value]])
- A player should not expect to get more than its added value. ([[Class 3 - Added Value and Irreplaceability#Defining added value|Class 3 › Defining added value]])

### From Class 8 - Strategic and Repeated Interactions
- NutraSweet charged about $70/lb against an estimated marginal cost of about $18/lb. ([[Class 8 - Strategic and Repeated Interactions#Case - Bitter Competition, the setup|Class 8 › Case - Bitter Competition, the setup]])
- The gap between $30 and $70 looked attractive for the entrant. ([[Class 8 - Strategic and Repeated Interactions#Case - Bitter Competition, the setup|Class 8 › Case - Bitter Competition, the setup]])
- HSC created $400-600M of value for Coke and Pepsi but captured little of it. ([[Class 8 - Strategic and Repeated Interactions#HSC's major mistake|Class 8 › HSC's major mistake]])
- HSC's presence allowed Coke and Pepsi to push NutraSweet's price down from $50/lb. ([[Class 8 - Strategic and Repeated Interactions#What happened|Class 8 › What happened]])
