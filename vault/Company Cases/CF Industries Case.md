# CF Industries Case

CF created value by controlling the supply chain, storage, and pricing information for fertilizer, using regulatory barriers to capture market advantage.

## Key Points
- CF created value by having ammonia where and when farmers needed it. ([[Class 2 - Value Creation and Capture#Case - CF Industries|Class 2 › Case - CF Industries]])
- CF captured value through terminals, which are heavily restricted by regulation (an entry barrier). ([[Class 2 - Value Creation and Capture#Case - CF Industries|Class 2 › Case - CF Industries]])
- Storage allowed CF to sell to the higher-priced agricultural market rather than the industrial market. ([[Class 2 - Value Creation and Capture#Case - CF Industries|Class 2 › Case - CF Industries]])
- The $3.8 billion expansion led competitors to cancel their own plans, acting as entry deterrence. ([[Class 2 - Value Creation and Capture#Case - CF Industries|Class 2 › Case - CF Industries]])
