# Intel Case

Intel's strategy shifted from DRAM to microprocessors, demonstrating how network effects and IP protection drive added value.

## Key Points
- Intel's strategy in DRAM involved innovation and product design, being first to market, pricing high and moving on. ([[Class 3 - Added Value and Irreplaceability#Case - Intel|Class 3 › Case - Intel]])
- Intel's added value in DRAM collapsed, but persisted in microprocessors because of network effects. ([[Class 3 - Added Value and Irreplaceability#Case - Intel|Class 3 › Case - Intel]])
- Intel captured added value through Intel Inside and a systems business. ([[Class 3 - Added Value and Irreplaceability#Case - Intel|Class 3 › Case - Intel]])
